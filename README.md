# Requisitos do Projeto

## Requisitos Funcionais

- [RF001] O usuário deve conseguir realizar login.
- [RF002] O sistema deve permitir cadastro de novos usuários.
- [RF003] O usuário pode recuperar a senha por e-mail.
- [RF004] O sistema deve gerar relatórios em PDF.

---

## Requisitos Não Funcionais

- [RNF001] O sistema deve responder em até 2 segundos.
- [RNF002] A aplicação deve ser compatível com dispositivos móveis.
- [RNF003] Os dados devem ser criptografados.
- [RNF004] O sistema deve ter disponibilidade de 99,9%.
